# Game-Automotion
Control the game, not with buttons — but with gestures! ✋🎮💻

Just built a real-time hand gesture-controlled system to play Up Hill Racing 2.
No keyboard, no mouse — just AI, Python, and pure innovation in action. ⚙️✨
This isn’t just gaming, it’s the future of human-computer interaction.

Built using: Python 🐍 | OpenCV 🧠 | MediaPipe ✨ | Computer Vision 👁️‍🗨️
